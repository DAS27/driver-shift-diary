# Проверка результата

## Автоматические проверки

```sh
make check
make build
```

Локально выполнены форматирование, `go vet`, `go test -race` и сборка бинарного файла. Серверные тесты выполняются также в GitHub Actions вместе со сборкой Docker-образа.

## Проверка в браузере

Проверено на демонстрационных данных:

1. Последний день (02.10.2026): 5 поездок, 13 800 ₸ выручки, 2070 ₸ комиссии, 11 730 ₸ чистого дохода.
2. Предыдущий день (01.10.2026): 2 поездки, 3900 ₸ выручки, 585 ₸ комиссии, 3315 ₸ чистого дохода.
3. Кнопка «Сегодня» и пустой день.
4. Форма: окончание до начала отклоняется с понятным сообщением.
5. Добавление поездки на 100,25 ₸ с комиссией 15,04 ₸: одна запись и 85,21 ₸ чистого дохода.
6. Повтор того же ввода: уведомление о дубле, количество остаётся равным 1.
7. Узкий экран: страница помещается по ширине, длинная таблица прокручивается внутри панели, разбивка оплаты доступна ниже списка.
8. В консоли браузера отсутствовали ошибки и предупреждения при этих действиях.

Браузерная проверка выполнялась на отдельной временной копии JSON. Тестовая добавленная поездка не включена в поставляемые демоданные.
