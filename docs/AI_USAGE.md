# Использование ИИ

Проект реализован с помощью OpenAI Codex по предоставленному условию. ИИ использовался для проектирования, написания Go-кода и интерфейса, тестов, документации и проверки в браузере.

## Реальная ошибка, найденная проверкой

В первой версии HTTP-маршрутов одновременно использовались `GET /` для статики и `/api/` для резервного обработчика. У `net/http.ServeMux` эти шаблоны конфликтуют: один более специфичен по методу, другой — по пути. Интеграционный тест завершился panic ещё при сборке обработчика.

После обнаружения ошибки резервный обработчик статики изменён на `/` с явной проверкой GET/HEAD. Тесты API повторно запущены. Этот случай показывает, почему сгенерированный код нужно запускать и проверять, даже когда отдельные функции выглядят корректно.

При проверке на экране 390 px обнаружилось ещё одно упущение: таблица расширяла всю страницу, потому что элемент CSS Grid сохранял минимальную ширину по содержимому. Добавлены `min-width: 0` для панели и `minmax(0, 1fr)` для колонки. Прокрутка таблицы теперь остаётся внутри панели; мобильный вид проверен повторно.

## Что проверялось отдельно

- Денежные расчёты в целых тиынах и контрольные итоги: 3900 − 585 = 3315 ₸.
- Дедупликация по нормализованным данным, а не только по клиентскому ID.
- Параллельные повторы и восстановление индексов после перезапуска.
- Отнесение поездок к локальному дню и работа интерфейса.

Проверки и исправления в этой сессии также выполнял Codex. Репозиторий не утверждает, что автор задания лично вручную исправлял код. Для анкеты раздел «что исправили сами» следует дополнить только реальными результатами собственного ревью и изменениями кандидата.
